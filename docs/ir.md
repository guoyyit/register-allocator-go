# IR 规范

中间表示（IR）是基于虚拟寄存器、由带标签基本块和终结指令构成控制流的
简单指令集。寄存器编号写成 `%N`（`N >= 0`），立即数写成十进制整数。

## 词法

- 注释：从 `;` 到行尾。
- 标识符：函数名与块名由非空白字符组成；块名以行尾的 `:` 结束。
- 立即数：可选符号的 64 位十进制整数。

## 程序结构

```
func <name>
param %a
param %b
<block>:
	<instr>
	<terminator>
```

- 一个程序包含至少一个函数，函数名唯一。
- 必须存在 `main`，它从共享内存的初始全零状态开始执行。
- `param` 必须出现在任何块之前，按调用约定顺序对应实参。
- 第一个块是入口块；每个块非空且必须以终结指令结尾。

## 指令

定义类指令产生一个新的虚拟寄存器，寄存器采用单赋值（SSA 风格，
但没有 phi 指令；跨迭代/跨分支合并的值通过共享内存传递）。

| 形式 | 语义 |
| --- | --- |
| `%d = const IMM` | 常量 |
| `%d = add %a, %b` / `sub` / `mul` | 整数运算（源可为立即数） |
| `%d = cmplt %a, %b` | 有符号小于，结果 0/1 |
| `%d = load %addr` | 从共享内存读一个字 |
| `store %addr, %val` | 写一个字到共享内存 |
| `br L` | 无条件跳转 |
| `brcond %c, Ltrue, Lfalse` | 条件跳转 |
| `%d = call f(ARGS...)` | 调用函数，参数为寄存器或立即数 |
| `ret %v` / `ret IMM` | 返回整数值 |

二元运算的源操作数允许使用立即数；跳转、存储、返回不定义寄存器。

## 校验规则（非法输入必须被拒绝）

- 未知助记符、缺少/多余目标寄存器、操作数数量错误。
- 使用未定义寄存器、块内先用后定义、使用点不被定义点支配（跨分支
  使用仅在某条路径上定义的值）。
- 重复的函数名、块名、参数或寄存器定义。
- 跳转到不存在的块；终结指令不在块末或块末不是终结指令。
- 存在入口不可达块；函数没有任何 `ret`。
- 调用未定义函数、实参数量与形参不符、直接递归（不支持）。

所有拒绝错误都带文件名与行号（见 `ir.Error`），便于定位。
